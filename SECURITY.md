# Security Policy

## Reporting a vulnerability

Please report security issues privately to:

**getsepolia@protonmail.de**

Please include:

-   Description
-   Steps to reproduce
-   Potential impact

Do **not** disclose vulnerabilities publicly before they have been
reviewed.

## Scope

Examples:

-   Payment verification bypass
-   Faucet abuse
-   Authentication issues
-   Remote code execution
-   XSS / CSRF
-   Inventory manipulation

## Out of scope

-   UI suggestions
-   Feature requests
-   Third-party wallet bugs
